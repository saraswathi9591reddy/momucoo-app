# Momucoo

Momucoo is a Flutter mobile app for pregnancy care and anemia screening: account and profile, CBC analysis, reports, dashboard history and emergency help. It is a conversion of the Momuco React web app.

## Run

```
flutter pub get
flutter run
```

Built and tested with Flutter 3.47.2.

See [CONVERSION_MAP.md](CONVERSION_MAP.md) for how each web page maps to a Flutter screen.
